# The Painfully Honest Out-of-Office

One out-of-office auto-reply, one sentence, 157 characters — painfully honest but still polite enough for a manager to forward:

> I'm away this week and, honestly, relieved to be unreachable — I'll answer your email when I'm back, rested enough to actually help instead of just replying.

It admits the private truth (relief at being unreachable, and that burnt-out replies help nobody) while promising a real answer on return, so it stays warm and professional instead of turning into a complaint.

## Run it

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt` (and a local `entry.txt` copy) and validates it first: 1–200 characters, one sentence, not whitespace only.
